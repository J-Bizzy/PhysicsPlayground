## §Phase 0 — Load-bearing defects

*Mechanical, testable, mostly invisible.*

Nothing here changes a design decision, so it needs no screenshot and no
approval to be correct. It is first because every item multiplies across all six
labs.

0.1  Undefined quaternions. Promote VectorFieldArrows.rotationFromYAxis(to:)
     -- which already has the near-antiparallel guard -- to a free
     RenderKit.rotation(from:to:), and use it at all 13 simd_quatf(from:to:)
     sites. Two are reachable in ordinary use: Callout.swift:207 builds every
     Bloom grip's leader from exactly [0,1,0] -> [0,-1,0] (Bloom.swift:226
     passes offset SIMD3(0,-0.046,0)), and FrozenVectors.swift:159 aims a frozen
     gravity arrow at exactly [0,-1,0]. The four yaw-only facings
     (Bloom:289, SpatialActionBank:193, SpatialLayerBank:93, SpatialPicker:155)
     should not use from:to: at all -- replace with
     simd_quatf(angle: atan2(flat.x, flat.z), axis: [0,1,0]), which is exact and
     states the intent. Add a test that builds a grip whose offset is straight
     down and asserts the leader's transform is finite and points down.

0.2  SoundPalette.warmUp() synthesises ~40 s of audio ON THE MAIN THREAD at
     first launch. SoundPalette is @MainActor (line 33), so the unstructured
     Task inherits it and the synchronous writeIfNeeded/writeAmbientIfNeeded run

     the Data. Also: version the three unversioned cache filenames the way
     ambient-lab-4.wav is versioned, or the comment at :136 is a rule we only
     followed once.

0.3  THE COLLIDER RULE, enforced by a test instead of by attention. Write ONE
     criterion test that walks every CollisionComponent in a built scene from
     each module and asserts each shape's extents <= its entity's visualBounds
     extents x a stated margin (1.15 is right). Then make it pass. The inventory
     is in the audit's P1-12 table; the two that break interaction outright are
     FieldRenderer.swift:357 (a 0.26 m sphere on a 0.5 x 0.5 x 0.012 plate,
     which makes every charge inside a capacitor unpinchable) and the pendulum

     GravityLabSpaceView:119 still carries span 50 deg / reach 0.30, whose
     comment reasons explicitly about "four discs". End-pair centres are 0.0494 m
     apart against a 0.068 m collider -- aim at 1x, hit -1x, run the solar system

     visual diameter 0.052 instead of the collider 0.068, stops at count 9, and
     only ever tests the default layout -- that is why this landed.

0.5  Two drags that throw their own result away. LabPlacement.swift:130 and
     HubSpaceView.swift:217 both compute travelled by measuring against a
     reference the very next line overwrites, so the quantity tested against the
     0.012 m tap threshold is ONE FRAME's hand displacement. Only a drag faster
     than ~1.08 m/s survives; a normal 0.3 m/s placement drag is read as a tap
     and recentres. Measure against the drag's own start. Both are headline verbs
     and both are untested -- add tests that drive N slow frames and assert the
     placement sticks.

0.6  Gesture and lifecycle leaks:
     - SpatialScale.swift:262 and :275 call rig.endGesture() -- which is the
       COMMIT -- on the suppressed path. Add cancelGesture() restoring the
       gesture-start scale/turn, and call that instead.
     - PinchLedger.clear() has no callers; one hand leaving the tracking volume

       it from the gesture onEnded handlers, or expire entries not seen for 0.5 s.

     - GeometryPipeline never stores its Task and never checks isCancelled, so a

       expose cancel(), check after the await, call it from renderer teardown.
     - Nothing can clear draggingID / grabs except a normal onEnded. Clear them

0.7  Two taps that destroy what they touch. KinematicsSpaceView:296 and

0.8  isImmersiveSpaceOpen is written by a Group (PlaygroundSpaceView:74), which

0.9  RoomModel.retain() never checks Task.isCancelled and release() is guarded on

## §Phase 2 — The spine

*The real answer to "it feels cluttered".*

The clutter is not too many features. Count the standing objects: Magnetism 6,
Pendulums 6, Projectiles ~11, Electric Fields ~12, Gravity Lab ~16, Circuits
~21. Magnetism and Pendulums prove the vocabulary can produce a calm room. What
the other four lack is a container -- every primitive is a peer with its own
anchor, its own update signature, its own collider and its own tap entry point.
That is why we have five different per-frame signatures, six hand-written
ordered handleTap if-chains, and a 274-line FieldInstrumentLayout.swift that
exists because one module had to hand-derive clearances between instruments with
no common parent (and SpatialActionBank.reach(forLabels:), the API meant to
provide that, has zero production callers).

Build the container. Sketch, to be argued with, not copied:

    @MainActor protocol Instrument: AnyObject {
        var root: Entity { get }
        /// Local footprint INCLUDING labels -- what a carrier needs to lay
        /// this out without collisions. Subsumes reach(forLabels:) and makes
        /// the clearance guarantee automatic instead of opt-in.
        var footprint: BoundingBox { get }
        func tick(_ context: InstrumentContext)   // the carrier calls this,
                                                  // never a SpaceView
        func handleTap(_ entity: Entity) -> Bool
        func beginDrag(_ entity: Entity, hand: SIMD3<Float>) -> Bool
        func updateDrag(hand: SIMD3<Float>) -> Bool
        func endDrag()
    }
    struct InstrumentContext {
        let viewer: SIMD3<Float>?
        let dt: Double
        let resetNonce: Int      // absorbs SpatialActionBank's special case
        let reduceMotion: Bool   // decided ONCE, see 2.5
        let nearestHand: SIMD3<Float>?   // drives recession, see 2.3
    }

    @MainActor final class InstrumentRail {
        enum Spine { case column(pitch: Float), row(pitch: Float), arc(FanLayout) }
        enum Presence {
            case pinned                        // control-and-readout: the law
                                               // forbids hiding these
            case summoned(handle: SummonHandle) // the default
        }
        func add(_ instrument: Instrument)   // refuses an instrument whose
                                             // collider exceeds its footprint
        func tick(anchor: SIMD3<Float>, context: InstrumentContext)
        func handleTap(_ entity: Entity) -> Bool   // ONE entry point per module
    }

    /// The only object a summoned rail contributes at rest: a small machined
    /// tab wearing the module accent, standing where the rail will unfold.
    @MainActor final class SummonHandle: Instrument {
        init(label: String, symbol: String, accent: UIColor)
        /// The load-bearing idea. The reason a layer bank "never folds" is that
        /// which layers are showing is information you need WHILE looking at the
        /// physics. That defeats a plain fold. It does not defeat a fold that
        /// keeps a one-line readout: a tab reading "Layers - lines, arrows" is
        /// both the summary and the door.
        var summary: (() -> String)?
    }

3.3  PHYSICS THAT IS VISIBLY WRONG. Fix in this order, each with a test:
     - The double pendulum cannot draw its own trail and every readout about it
       lies, because step never writes `state` for kind == .double -- so the
       chaotic trace the rig exists for is undrawable, the force arrows draw a
       constant mg on a visibly accelerating bob, the period label stamps
       2pi sqrt(L1/g) on a system with no period, the card reads v 0.00 m/s
       forever, pausing produces no freeze sculpt, and grabbing it freezes it and
       refuses to follow the hand.
     - The ammeter has exactly two reachable outputs, FUSE and zero, and its
       live-detect threshold sits BELOW the solver's own leak floor, so it
       refuses on a loop the user just broke. Stamp a real meter element and
       derive both thresholds from CircuitSolver.leakConductance.

       the card reads Force 0.00 N under a visible cyclotron orbit; potential
       ignores the capacitor, so it can show a large E beside 0.00 V; and
       cyclotronRadius is quoted from a launchSpeed the probe leaves immediately.
       Splitting the card into an E row and a v x B row IS the Lorentz lesson.
     - The predicted arc and the real ball bounce differently -- simulate passes
       radius 0, ignores hit.t, and bounces the centre off y = 0. With a
       basketball the white arc corners 12 cm off the wall, and "bounces
       included" is the module's central claim.
     - Pendulum bob collisions apply impulses off the constraint tangent and the
       constraint step then reinterprets the radial part as speed, so off-axis
       pairs GAIN energy on every contact (masked in the cradle, which is the
       only collision test). And resolveBobCollisions aborts for the ENTIRE bench

       from the well without moving them and nothing in the room collides again.

       traced from the bar field, at r/L = 0.92, which MagneticField.swift's own
       header disqualifies. The most-repeated interaction in the module is
       computed in the regime the code says is wrong.
     - Gravity Lab's orbit-ring occluders are passed in the wrong frame (bead
       relative to focus, centres absolute), masked only because reset() puts the
       Sun at the origin -- press "Twin suns" and the ring becomes intermittently
       un-grabbable.
     - Circuits: removeComponent leaves pendingTerminal dangling, so deleting an
       armed part and then tapping any terminal appends an invisible,
       un-pinchable, budget-consuming wire that persists to disk.

3.4  ONE CANON FOR NUMBERS. PhysicsFormat is bypassed by nearly every in-room

## Why this order

**Phase 0 first** because those defects multiply — one undefined quaternion is in
every control ring in every lab, one oversize collider makes a whole capacitor
interior unpinchable, and none of it needs a design decision or a screenshot to
be correct.

**Phase 1 second** because it is the only thing on this list that costs the app
sales. Everything else is a quality gap a buyer discovers after paying; the
front door is one they hit in the first ninety seconds.

**Phase 2 third** because the container is what phase 3 hangs on. The in-room
experiment surface, the Circuits preset fan and the Lagrange callout are all new
standing objects — adding them to the rooms as they are now makes the clutter
worse. Build the spine, then hang things on it.

**Phase 3 last** and it is the payoff. None of it is new content. It is twenty
experiments, five circuits, five paragraphs and four explanations that are
already written, already tested, and already compiled into the binary with
nobody to read them.
